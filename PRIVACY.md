# Privacy policy

Last updated: 8 November 2026

This policy covers "Somebody Always Pays Stats", a small internal tool that the Somebody Always Pays channel uses to read the analytics of its own YouTube channel.

## What it accesses

With the channel owner's permission (Google OAuth), the tool reads, without changing anything:

- public details of the owner's own channel and videos (YouTube Data API, read-only);
- the channel's YouTube Analytics reports, such as views, watch time, audience retention, traffic sources, countries and estimated revenue (YouTube Analytics API, read-only).

## What it does with the data

The data is saved as report files on the channel owner's own computer and is used only to decide what videos to make next. It is not sold, shared with third parties, used for advertising or combined with other data. The tool has no other users and does not access anyone else's account.

## Storage and deletion

Access tokens are kept only on the owner's computer. Access can be revoked at any time at https://myaccount.google.com/permissions, which stops the tool from reading any further data. Deleting the local report files removes the saved data.

## Google API Services

The tool's use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. It uses YouTube API Services; see the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy).
